How to keep this honest:
- Every task is an issue with one assignee; every change goes through a pull request by the person who did it.
- Commits use the person's own git name and email. Do not squash away or rewrite history.
- If AI assistance was used for a piece of work, say so in its pull request, following the group's and the instructor's AI-disclosure rules.
